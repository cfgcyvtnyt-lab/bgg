## A. 버그

### A1. 계정을 전환해도 탭 화면들이 예전 계정 데이터를 보여줌 (가장 중요)
탭 다섯 개를 살려두게 되면서 생긴 부작용. 기록·인사이트(계정별 데이터)와
컬렉션의 내 평점·하고싶어요 표시가 전환 후에도 예전 계정 것으로 남는다.
예전엔 화면을 오갈 때마다 새로 만들어져서 가려졌던 문제.
- 확인: PlaysPage / CollectionPage / FeedPage / InsightsPage 모두 currentUser에
  반응하는 재조회 effect가 없음.
- 고치는 방향: 패널에 `key={currentUser.id}`를 줘서 전환 시 통째로 다시 만들거나,
  각 화면이 currentUser 변화에 목록을 리셋하게. 전자가 한 줄이고 안전.

### A2. PC 표 모드의 wide-mode가 다른 탭으로 샘
CollectionPage가 `body.wide-mode`를 unmount cleanup으로 지우는데, 이제 탭이
unmount되지 않는다. 표 모드 상태로 다른 탭에 가면 body에 클래스가 남아
모든 패널이 1400px로 퍼진다. (PC 전용 문제)
- 고치는 방향: cleanup 의존 대신 "컬렉션 탭이 활성 + 표 모드"일 때만 클래스 유지.

### A3. 모달·라이트박스 열림 중 배경 스크롤 잠금이 무효
Modal이 `document.body.style.overflow`를 잠그는데, 스크롤 주체가 `.app-pane`으로
바뀌어서 아무것도 안 잠근다. 라이트박스 배경도 touchmove를 안 막아서 iOS에서
뒤 화면이 같이 스크롤될 수 있다.
- 고치는 방향: 열릴 때 활성 `.app-pane`에 overflow: hidden, 라이트박스 배경에서
  touchmove preventDefault.

### A4. 미번역 게임 상세를 열 때마다 막힌 번역 API 재시도
translate가 실패해도 기록을 안 남겨서, 컬렉션 밖 게임(BGA로만 해본 것 등) 상세를
열 때마다 구글 gtx → MyMemory를 다시 때린다. 매번 느리고 429 스팸.
"번역 중..."이 계속 뜨는 게 이것.
- 고치는 방향: 실패 시각을 game에 기록하고 하루 안엔 재시도 안 함,
  또는 수동 "번역" 버튼으로 전환.

### A5. 목록 캐시 무효화 누락
`clearListCache()`가 기록 저장/삭제에만 있다. 다음 동작 후엔 최대 5분(TTL) 동안
낡은 목록이 보인다:
- 컬렉션 정보 수정(상태·가격·태그), 평점/하고싶어요 변경
- 기록 화면 안에서 사진 삭제(deleteExistingPhoto)
- BGA 임포트로 판 추가
- 장소 이름 변경/삭제(기록 목록의 장소 표기)

### A6. (실기기 확인 필요) iOS 홈화면에서 상태표시줄 겹침 가능성
`apple-mobile-web-app-status-bar-style=black-translucent`는 viewport-fit 없이도
콘텐츠를 상태표시줄 밑까지 넣을 수 있다. 지금 아이폰에서 괜찮아 보인다고
하셨지만, 문제가 재발하면 이 값을 `black`으로 바꾸는 게 첫 시도.
